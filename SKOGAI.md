Open Knowledge CLI: turns repository Markdown into managed, searchable
knowledge for people and agents. This repo is a fork vendored into the
skogai monorepo as `ofk-tools` (upstream remote `skogai2/okf2`).

For contribution rules, CLI behavior, and the colocated `Wiki/`, go to
`AGENTS.md`. For product vision and scope, go to `PRODUCT.md`. This file
only orients an agent arriving via the skogai orchestrator — it doesn't
restate either.

The skogai-specific reason this fork lives in the monorepo (rather than
being consumed as a dependency, or why `okf2`/`ofk-tools` diverges from
upstream naming) is undocumented in this repo.
